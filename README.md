# Amazon Sales Analysis
Amazon Sales Analysis using SQL and Power BI to analyze sales performance, orders, fulfillment, products, and sales channels.
## Project Overview
This project analyzes Amazon sales data to understand sales performance, order trends, product categories, fulfillment methods, sales channels, and other sales-related patterns.
## Objective
- Analyze overall sales and performance.
- Examine order and quantity trends.
- Analyze product and category performance.
- Compare fulfillment methods.
- Analyze sales channels.
- Present key sales metrics through an interactive Power BI dashboard.
  ## Tools & Technologies
  - SQL
  - PostgreSQL
  - Power BI
  - Github
  ## SQL Analysis
  SQL was used to analyze Amazon sales data and generate business-focused metrics and summaries covering orders, sales, products, categories, fulfillment, and sales channels.
  ## Power BI Dashboard
  An interactive Power BI Dashboard was created to visualize Amazon sales performance.
  The dashboard includes analysis of:
  - Sales performance
  - Monthly sales trends
  - Product categories
  - Fulfillment
  - Sales channels
  - Orders and quantities
  ## Key Business Insights
  - Sales performance can vary across product categories and sales channels.
  - Monthly analysis helps identify changes in sales trends.
  - Fulfillment methods can be compared to understand order distribution.
  - Product and category analysis helps identify differences in sales performance.
  - The  Dashboard provides a consolidated view of Amazon sales activity.
